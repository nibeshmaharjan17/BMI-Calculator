# 🚀 BMI Pro | Advanced Health Analytics

A modern, responsive, and aesthetic Body Mass Index (BMI) calculator built with pure Frontend technologies. This project focuses on high-quality UX/UI, precise unit conversion, and dynamic data visualization.

## ✨ Features
* **Multi-Unit Support:** Seamlessly switch between Metric (kg, cm, m) and Imperial (lb, in, ft) units.
* **Real-time Analysis:** Instant BMI calculation with categorization (Underweight, Healthy, Overweight, Obese).
* **Dynamic UI:** The interface shifts colors and progress bars based on the health results.
* **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop views.
* **Glassmorphic Aesthetic:** Modern dark-themed UI with frosted glass effects and smooth CSS transitions.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure for accessibility.
* **CSS3:** Custom properties (variables), Flexbox, and Keyframe animations.
* **JavaScript (ES6):** DOM manipulation, event listeners, and unit conversion logic.

## 📐 The Logic
The application converts all user inputs into the metric system internally before applying the standard formula:
$$BMI = \frac{mass(kg)}{height(m)^2}$$
